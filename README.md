# Subdomain lists to IPV4 Address Converter

## This tool converts the subdomains in a list to IP V4 address using dig tool.

### Installation

#### 1. Clone the git repo
#### 2.	Edit the input_file variable to the file containing the subdomains.
#### 3. Change directory to the git repo
#### 4. Change permission on the subs_ip4.sh to execute
#### 5. Run ./subs_ip4.sh in your terminal
